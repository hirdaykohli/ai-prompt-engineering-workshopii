# AI Prompt Engineering Workshop

A hands-on project focused on **prompt engineering for Large Language Models (LLMs)**, demonstrating how structured instructions, context, examples, and output constraints can be used to improve the quality and consistency of AI-generated responses.

## 📌 Overview

Prompt engineering is the process of designing and refining instructions to effectively communicate tasks to AI models.

This project explores practical prompting techniques through interactive experiments and examples. It is designed to help learners understand how prompt structure influences the accuracy, relevance, and format of LLM outputs.

## 🎯 Objectives

* Understand the fundamentals of prompt engineering
* Learn how to structure effective AI prompts
* Experiment with different prompting techniques
* Improve the quality and consistency of LLM responses
* Learn prompt refinement and optimization
* Control AI responses using constraints and output formats
* Develop reusable prompts for real-world applications

## 🔄 Prompt Engineering Workflow

```text
Define the Objective
        ↓
Provide Context
        ↓
Assign a Role
        ↓
Define the Task
        ↓
Add Constraints
        ↓
Specify Output Format
        ↓
Test the Prompt
        ↓
Evaluate the Response
        ↓
Refine the Prompt
```

## 💡 Example

### Basic Prompt

```text
Explain machine learning.
```

### Improved Prompt

```text
Act as a machine learning instructor.

Explain machine learning to a beginner using:
1. A simple definition
2. Three real-world examples
3. A short explanation of supervised and unsupervised learning
4. A concise summary

Use simple language and avoid unnecessary technical terminology.
```

The second prompt provides additional **role, context, requirements, structure, and constraints**, making the expected response clearer.
